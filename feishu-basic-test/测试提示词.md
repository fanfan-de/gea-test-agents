# 飞书基础测试提示词

在 Studio 调试或飞书中逐项发送。记录实际结果，不以 Agent 声称成功代替工具结果。

| 场景           | 提示词或操作                                                                                     | 预期                                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| 基础对话       | `基础检查`                                                                                       | 回复 `FEISHU_AGENT_OK`。                                                                                |
| Connector 发现 | `扩展检查`                                                                                       | 真实调用官方 Skills 列表和 CLI help；两次成功才回复 `FEISHU_CONNECTOR_OK`。缺少 Connection 时明确提示。 |
| 私聊记忆       | `记住测试词 FEISHU_SMOKE_20261012。`，再问 `刚才的测试词是什么？`                                | 同一私聊能回忆；另一用户的私聊不知道该测试词。                                                          |
| 群聊触发       | 在测试群中 `@机器人 基础检查`                                                                    | 在该消息的话题下回复。普通群消息、只 @ 其他人、只 @ 机器人而没有正文都不触发。                          |
| 群聊话题       | 用户 A 在话题里 `@机器人 记住测试词 TOPIC_A`，用户 B 在同一话题里 `@机器人 刚才的测试词是什么？` | 同一话题共享记忆；另一个新话题不知道 `TOPIC_A`。                                                        |
| 机器人读取     | `先读取对应官方 Skill 和 help，再以 --as bot 读取这个测试文档：<测试文档链接>。只读取，不修改。` | 用当前 Channel 应用的机器人身份执行，并引用真实结果；没权限则明确失败。                                 |
| 个人读取       | `以 --as user 读取这个测试文档：<测试文档链接>。只读取，不修改。`                                | 未授权时返回当前发送人的个人授权链接；该发送人授权后重新发送提示词能读取其获授权文档。                  |
| 权限拒绝       | 用上述读取提示词提供一个无权访问的测试文档                                                       | 明确报告拒绝，不编造内容，不切换身份绕过拒绝。                                                          |

Studio 调试使用独立的 Feishu Connection。飞书 Channel 内的调用使用 Channel 应用与本次发送人，二者分别验收。

如需测试独立发消息，先由你在当前会话明确给出测试目标、身份和消息，例如：

> 以 --as bot 向测试会话 <chat_id> 发送一条消息，内容为“FEISHU_SEND_TEST”。先查对应官方 Skill 和 help，发送一次，并报告实际结果。

普通 Channel 回复不需要单独调用发消息工具。
